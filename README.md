# ОГЭ-ВЫЖИМКА — Интерактивный образовательный веб-портал

Образовательный веб-сайт, разработанный в рамках индивидуального итогового проекта в 9 классе.

## 🎯 Назначение проекта
Предоставить девятиклассникам концентрированную выжимку («без воды») по подготовке к ОГЭ по **всем 11 предметам**:
- 📐 **Математика** (Реальная математика 1-5, Алгебра, Геометрия, формулы и правила)
- 📖 **Русский язык** (Сжатие текста для изложения, тест 2-12, шаблоны сочинения 13.3)
- ⚖️ **Обществознание** (Экономика, политика, право, социальные нормы, Конституция)
- 💻 **Информатика** (Логика, графы, кодирование, алгоритмы Python, Excel-формулы)
- ⚡ **Физика** (Механика, теплота, электричество, оптика, лабораторная №17)
- 🧪 **Химия** (Периодический закон, свойства веществ, качественные реакции, ОВР)
- 🌿 **Биология** (Клетка, анатомия человека, царства живой природы, экосистемы)
- 🌍 **География** (Топографические карты, азимуты, часовые пояса РФ, климатограммы)
- 🏛️ **История** (Хронология с IX века по начало XX века, термины, культура)
- 🇬🇧 **Английский язык** (Времена, пассивный залог, словообразование, готовый шаблон Email)
- 📚 **Литература** (Теория, стихотворные размеры, анализ произведений школьной программы)

## 🚀 Ключевые возможности сайта

1. **База знаний и шпаргалки**:
   - Карточки с ключевыми формулами и правилами.
   - Раздел «Опасные ловушки и частые ошибки» — на чем заваливаются до 70% учеников.
   - Официальный список разрешенных ФИПИ материалов на экзамене.

2. **Интерактивный экспресс-тренажёр (Квиз)**:
   - Реальные вопросы формата ОГЭ по каждому предмету.
   - Мгновенная проверка с подсчетом баллов.
   - Подробное пошаговое объяснение правильного решения.

3. **Калькулятор первичных баллов ФИПИ**:
   - Точный перевод набранных первичных баллов в школьную отметку (2, 3, 4, 5).
   - Поддержка критических условий ФИПИ:
     - Обязательный порог по геометрии в математике (минимум 2 балла).
     - Порог грамотности ГК1-ГК4 в русском языке.

4. **Интерактивный чек-лист готовности**:
   - Возможность отмечать пройденные темы галочками.
   - Расчет процента готовности к экзамену в реальном времени.
   - Автоматическое сохранение прогресса в браузере (`localStorage`).

5. **Мгновенный глобальный поиск**:
   - Быстрый поиск по всем предметам сразу (формулы, термины, ловушки).

6. **Дизайн и адаптивность**:
   - Переключение темной и светлой тем оформления.
   - Полная адаптивность под смартфоны, планшеты и мониторы ПК.
   - Кнопка «Печать» — готовая печатная шпаргалка на бумаге.

## 🌐 Способы запуска и доступ

### 1. Открытие файла напрямую (без интернета)
Дважды кликните по файлу `index.html`.

### 2. Локальный сервер (Localhost)
Дважды кликните по файлу `start_server.bat`. Сайт запустится по адресу:
`http://localhost:8080`

### 3. Доступ из интернета для кого угодно (Cloudflare Tunnel)
Дважды кликните по файлу `start_cloudflare_tunnel.bat`. В открывшемся окне отобразится публичная безопасная ссылка HTTPS вида:
`https://<имя>.trycloudflare.com`
Эту ссылку можно отправить одноклассникам или учителю — они смогут открыть сайт с любого телефона или компьютера!
